# PPT 制作提示词（可复用模板，沉淀自 ECHOPulse 组会汇报 v8）

用途：把一篇论文 / 一份材料做成组会汇报级别的全英文 PPT。输出风格介于"v5 简洁风"与"v7 强化风"之间：结构清楚、结论醒目，但克制装饰、不花哨。

【风格总原则（先读这条）】

- 参照系：简洁版 = v5（白底、深蓝标题栏、1–2 色语义、规整网格）；强化版 = v7（圆角卡片、彩色胶囊 chip、底部结论横幅）。本模板取"中间档"：保留 v7 的"底部一句话结论 + 原生表格 + 自绘图"，但所有装饰减半——圆角更小、实色胶囊更少、语义色只在表格/关键结论出现。
- 一句话检查法：如果一页上出现超过 2 种高饱和底色（深蓝之外），就删掉多余的。

【设计基线（硬性）】

- 画布 16:9，逻辑尺寸 1280×720（PPTX EMU 应为 12192000×6858000）。
- 字体：全部使用 微软雅黑（Microsoft YaHei），不混用花体；中文与英文同字体。
- 字号阶梯：封面大标题 44pt、内容页标题栏 20pt（白字加粗）、小节眉标 12pt（accent 色加粗）、正文 13–15pt、卡片正文 12–13.5pt、表格 11–12.5pt、角标/出处 11pt。行距 1.25–1.4，宁可偏松不可挤。
- 配色表：
  - 主色 navy #1F3864（标题栏、标签条）
  - accent #2E5B8F，蓝 #2F6FB3（次级元素、箭头）
  - 卡片底 #F2F6FB，边框 #DCE3EC（浅于 v7 的 #D9E2F0）
  - 正文 #333333；次级文字 #666666/#8A8A8A/#AAAAAA
  - 语义色：绿 #2F6F34（正向/最优）、橙 #B07C2F（警示/开卷对比）、红 #B03030（负面），只用于表格重点行与关键提示
  - 中性方块：#EEEEEE 底 + #D5DCE6 边（例如掩码生成网格的空格）
- 内容页固定骨架（每一页都齐全）：
  1. 左上小节眉标：大写字样 + 12pt accent 加粗（METHOD / EXPERIMENTS / SUMMARY…）；
  2. 深蓝标题栏：矩形 (72, 44, 1136, 54)，白字 20pt 加粗；
  3. 右下页码：11pt 灰字；
  4. 底部"一句话结论"：浅灰条 (#EFF3F9) + 14pt 加粗 navy 结论句，无圆角、无色条（比 v7 更朴素）。

【内容组织】

- 全英文；每页一个"可当开关句"的结论型标题；正文只做支撑，禁止念表。
- 页数建议 18–22；一张表只挑 2–4 个锚点数字讲；其余写"趋势一致，详见论文表 X"。
- 必须主动交代不公平对比（开卷 vs 闭卷）、论文内部数据不一致、易混术语。
- 深度控制：读者理解有限时，每页给"结论 + 类比/直觉 + 一个可验算数字"，复杂机制标注出处章节。
- 每页写英文演讲备注（2–4 句），含来源与讲法提示。

【自绘图规则（强制）】

- 流程图 / 示意图一律用"文本框 + 图形"（rect / roundRect / ellipse / textbox / connector）现画，禁止固定图片承载可编辑图形。
- 间距：元素之间至少留 8px，新图形块默认 10–16px；方块文字 9–13pt 居中；胶囊 chip 圆角取高一半。
- 装饰克制：默认 chip 用"白底 + 浅蓝边 + navy 字"的描边款，不用实色填充；一页中实色填充块不超过 2 个。
- 重复性网格必须线性对齐并程序化校验：
  - 例子（掩码生成填充分步）：每轮一行，8 个等大方格（34×34 px，行距 64 px、列距 42 px，起点相同），空格 = 灰底 #EEEEEE + "?"，已填 = 绿底 + "✓"；行标签为深蓝小条 (188×30) 白色加粗文字；行数、列数、步长必须用同一组参数生成；
  - 画完必须核对 layout JSON：同组元素 x 步长一致、y 行距一致、尺寸一致，任何"歪/错位"都算不合格。
- 几何检查（每次必做）：所有元素不越出 1280×720；任意两个含文字的文本框重叠面积 < 较小框面积的 35%；箭头用 connector 而非裸线条。

【论文原图】

- 300dpi 渲染 PDF 页面，按 PDF 图像对象边界裁剪，只贴图本身；图下方 11pt 灰字注明出处与一句话说明。

【表格（强制原生可编辑）】

- 原生 table，禁止截图；表头深蓝底白字加粗，隔行浅色；重点行用绿/橙/红底色并加粗（表内语义色不受"每页 2 个实色块"限制）。
- 数值与论文一致，标注 ↓/↑ 方向与单位，跨行比较注明数据集与条件。

【验证流程（每次必做）】

- 导出每页 layout JSON：越界、重叠、网格对齐三项人工/脚本核对。
- finalizePresentation 固化：要求 0 警告、页数与声明一致、表格所在页正确、字体策略 user_request（微软雅黑）。
- 交付前逐页渲染 PNG 复核（人工或识图），重点看裁切、溢出、堆叠、错位。

【输出前自检清单】

- [ ] 全英文；微软雅黑；字号阶梯符合基线
- [ ] 每页：眉标 + 深蓝标题栏 + 页码 + 底部一句话结论（灰条朴素版）
- [ ] 装饰克制：高饱和实色块每页 ≤2；chip 默认描边款
- [ ] 自绘图几何检查 0 冲突、无越界；重复网格对齐（步长/尺寸一致）
- [ ] 表格原生、数值一致、重点行有语义底色
- [ ] 论文图 300dpi 裁剪、带出处
- [ ] 每页英文演讲备注
- [ ] 校验器 0 警告；页数与计划一致
