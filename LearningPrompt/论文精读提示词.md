请用「宏观 → 逐层 → 细节」的方式讲解这篇论文：<论文标题 / 文件路径>。

我读论文是为了学知识，不是做英语阅读理解，也不是揣测作者意图。**我是知识与论文阅读的"双小白"**：脑子里没有现成的知识体系，默认我什么都没有，从头建立。

【讲解流程（每个部分固定 6 步）】

1. **英文原文**：先把这一部分的英文原文完整输出（可分段），让我先看原版。
2. **整体印象**：2 分钟鸟瞰——这部分在全论文里扮演什么角色、大概说了什么。
3. **逐句翻译拆解**：原句 → 逐词/逐短语中文对应 → 整句通顺翻译 → 值得注意的知识点。长难句先拆语法骨架（主语—谓语—宾语主干 → 修饰成分 → 语义），不许直接甩整句译文。
4. **🧠 知识层（重头）**：见【知识层硬性要求】。
5. **术语卡片**：英文术语逐词讲：词源拆解 → 中文含义 → 定义 + 例子 + 一句话直觉。
6. **一页纸总结 + 一分钟回顾**。

【知识层硬性要求】

- **从零建体系，不成知识点堆砌**：从"没有它行不行 / 为什么需要它"讲起，按"问题 → 方案 → 还不够 → 下一个问题"的链条组织；明确上一步解决了什么、这一步还缺什么。
- **每个关键机制必须配具体数字演示**：小维度、两三个 token，把输入值、计算过程、输出值用数字写出来，让我能亲手验算（如 embedding 查表、QKV 投影、softmax、掩码、残差、LayerNorm、FFN）。
- **矩阵/向量例子必须完整可验算**：(a) 给出矩阵具体数值；(b) 标明维度关系和向量约定（每行一个词 vs 每列一个词，互为转置，说清用的是哪种）；(c) 说明 W 形状 = 输入维 × 输出维，输出维可以不同于输入维（如多头 512→64，W 不是方阵）。
- **类比不能替代解释**：比喻/类比之后必须紧跟公式和数字例子。
- **论文记号要标明"状态"**：某符号（如 xₙ）在这一刻是原始 token、embedding、还是加过位置编码，用"数据流阶段"标注讲清楚。
- **记号从论文、不做缩写**：一律使用论文原记号（如 d_model、d_k、d_v、d_ff、W^O），不允许自行改写成 D 等变体；Unicode 有下标字形的（hₜ、xₜ、dₖ、dᵥ）尽量用下标渲染，没有的（d_model 中的 m、d_ff 中的 f）就写论文原样，不去硬凑。
- **任何新记号必须先定义再使用**：出现公式符号（如 Q_dec、K_enc、V_enc、head_i、Wᵒ、d_k）时，先讲它是什么、从哪一步来、形状如何，再进入公式。
- **公式不得裸放**：任何公式必须当场解释每个符号的含义、输入输出形状和整体作用，配数字演示或工作流说明；属于后面才教的内容，先给一句话直觉并说明"推导在后面"。
- **通用记号必须实例化**：公式里出现 x、Sublayer(x) 这类泛指符号时，必须映射到具体数据（如子层①的 x=D_in、子层②的 x=D_mid、子层③的 x=D_cross），不许含糊。
- **长难句先给语法骨架**：先拆主干，再补修饰，最后翻译。
- **禁止敷衍性省略词**：不使用"同上""同理""应该""大概"来替代完整表述；表格宁可重复展开，不许含糊带过。
- **训练 vs 推理必须分开讲**：凡涉及 Decoder 输入、自回归、右移、掩码、batch 等概念，必须分别说明"训练时"和"推理时"各自是什么样，两个视角各讲一遍。
- **术语首次出现给"定义 + 例子 + 类比"三件套**。

【小步递进】

每次只讲一小块，讲完就停，等我确认再继续。每轮开头标明"当前第几步 / 论文走到哪了"，结尾问是否继续下一步。

【讲解风格】

- 易混概念用表格；抽象概念用类比 + 数字例子；关键设计讲"为什么"。
- 按顺序记忆的知识，先讲根本原因或分类依据，让清单从原理里自然推导出来。
- 主动提醒常见坑（歧义译文、论文内部数据不一致、易混符号、易混概念如 layer vs sublayer）。
- 我指定重点时，其他内容一句话带过，不平均用力。

【数学公式渲染要求（硬性）】

- 行内符号一律用 Unicode 字符（hₜ , xₜ , dₖ , √ , ᵀ , ·），符号后若紧跟标点就在符号与标点之间加一个半角空格（英文原文引用同样处理）；只有独立成行的重点公式才用 $$…$$ 块级；输出前自查：正文里不得出现裸的 $、\、下划线。

## 附录 A：为什么聊天里行内 $…$ 不渲染（根因备忘）

本机 Codex 桌面版的聊天渲染器把 markdown 管线配置为 remarkPlugins: [[remarkMath, { singleDollarTextMath: false }]], rehypePlugins: [rehypeKatex]，即行内 $…$ 被硬编码禁用，只有 $$…$$ 可用；config.toml 无此开关，应用为签名包不可改。→ 行内符号用 Unicode，独立公式用 $$…$$。
